01

品牌定位与调性

Positioning

名字从「轻书」改为「轻阅」：书是物，阅是动作。产品卖的不是文件管理器，而是「翻开就读」的那一下。

一句话定位

把 txt 读成一本书——有扉页、有藏书章、有页码，且不联网。

为谁而做

攒了几百兆 txt 的读者：不想整理元数据，不想注册账号，只想接着上次那行继续读。

承自易笺

纸黄底、靛蓝字、格纹窗框、统一封面配朱红丝带、自动扉页与藏书章——纯文本也能有装帧感。

不同于易笺

没有 CDN 字体、没有官网依赖、没有 128 MB 上限、没有「服务不可用」。离线是默认，不是兜底。

三条设计原则

01

正文永远优先

界面可以退场：阅读时只剩文字、页码和一条细进度。控件是召之即来的，不是常驻的。

02

离线是默认

每个功能先验收断网状态。任何「要联网才好看」的设计，都要给出本地替代。

03

装帧感来自细节

扉页、藏书章、丝带、格纹、页码——不是装饰，而是让纯文本被当作一本书对待。

调性

是

纸黄（暖、旧、不刺眼）、靛蓝（墨迹般的沉）、朱砂（印章与丝带）、楷体（书卷气）、格纹（布面精装的窗框）。整体像一本 80 年代排印良好的平装书。

不是

不是极简白、不是毛玻璃、不是大圆角糖果色、不是渐变霓虹。易笺的「好看」来自印刷品的秩序感，我们沿用这套秩序，而不是另造一套。

品牌声音

场景不说说
导入完成书书到手啦～已导入 3 本，识别出《聊斋志异》等 2 个书名
编码识别正在智能解析中…检测到 GB18030，已按此编码打开
同步未配置同步失败，请检查网络当前为单机模式，阅读不受影响
章节识别智能分析完成识别 128 章；有 2 处疑似标题，可手动标记
文案原则：说人话、报事实、给下一步。绝不承诺「永久保存」——只说「已保存到本机」。
02

向易笺学什么

What We Learned

把易笺（SimpleTextReader v1.6.9.4）的功能、做法与用户口碑逐条拆开，分成「照搬」「改造」「补上」「不做」四类。这是本方案最重要的输入。

一、它的十二条亮点

能力易笺的做法为什么是亮点
百兆秒开本地解析 + 首次处理后缓存，二次打开直接读缓存；自动识别编码把「打开一个文件」的成本压到接近零，这是品类的入场券
书名/作者识别支持《书名》作者：xx.txt、书名.[作者].txt、Bookname by author.txt 三种命名导入后不用手填元数据，书架立刻像样
章节正则中英文标题正则；v1.6.4 起可从文档自身学习标题规律；支持行首 [::] 手动标记标题承认正则不可能完美，并且给了人工兜底——这是成熟设计
脚注抓取正文用 ①–㊿ 引用，行首同符号开头的行作为注释，每段可重新编号把 txt 里约定俗成的「伪脚注」变成真注释，古籍与网文通吃
广告清洗针对塞班、知轩藏书等来源的规则化清洗直接提升正文纯净度，且默认无感
自动扉页标题 + 作者 + 一枚朱红藏书章（中英不同），可在设置中关掉纯文本第一次「像一本书」，情绪价值极高
自动封面统一靛蓝封面 + 书名 + 作者条 + 朱红丝带，颜色随主题变化零素材也能得到整齐的书架，比抓封面图可靠得多
逐行进度精确到行的阅读进度，配合文件缓存「关掉再开就在原处」，是阅读器最被低估的体验
目录简化收起时只显示章名主干（去掉「正文/第X卷」前缀），悬停或展开时给全名长章名不挤压版面，同时不丢信息
字体分离标题字体与正文字体分开；可拖入 3 个自定义 TTF/OTF；内置多款可商用字体尊重「读者想用自己的字」这件事
键盘与开关←→ 翻页、PgUp/PgDn 跳章、Esc 回书架；Alt/Option+点封面强制重处理；URL 参数可关书架/设置/秒开给重度用户一条快车道，也给调试留后门
多入口网页、PWA、Chrome/Edge/Firefox 扩展（含无界面版）、Docker把「打开」这件事做得足够短

二、吸收决策

决策项目轻阅怎么做
照搬自动扉页 + 藏书章保留，作为每本书的第一屏；可在设置里关闭；印章文字用本书首字与「藏书」组合
照搬统一封面 + 丝带 + 书架三种排序在读书按最近阅读、未读按书名、读完按完成时间；封面颜色由主题色决定
照搬目录简化名 / 悬停展开直接采用，见视觉稿左侧章节栏
照搬PgUp/PgDn 跳章、Esc 回书架、Alt+点击重处理全部保留，并支持自定义与冲突检测
改造网络字体 / 12 款在线字体改为「本地字体 + 自带子集 + 用户拖入字体」；字体文件存 IndexedDB，用 FontFace 注册，永不请求外网
改造广告清洗（仅两家来源）规则可编辑、可关闭；导入后给一份「清洗报告」（移除 N 行、命中哪条规则），不做黑箱
改造脚注（行首符号配对）保留语法，交互升级为「点数字看浮层」，并汇总到书末注释页；无脚注时零打扰
改造逐行进度升级为「块 + 行 + 字符偏移」三重锚点：换字号、换设备都不漂
改造按章节分页 / 无限滚动分页为主路径；滚动模式用块级虚拟化；无章节时退化为按块分页，仍可百分比跳转
改造界面语言随书切换沿用（中/英），但仅影响界面文案，不改排版规则；预留 i18n 字典
改造URL 参数开关改为设置项 + 一组只读诊断参数，不在正式入口暴露
补上书签与摘录易笺只有进度。轻阅补书签（可加备注）、摘录（选中即存）、书签列表侧栏
补上全书搜索基于块索引做增量扫描，命中结果带上下文与章节定位，全程本地
补上排版参数在行高/字号/主题色之外，补行宽、段距、首行缩进、对齐、标点禁则
补上移动端易笺以桌面为主。轻阅做手势分区、底部抽屉、底部 Tab，触控目标 ≥ 44px
补上可选同步默认单机；同步是适配层，失败静默降级，绝不影响本地功能
不做账号、社区、书评、推荐、云书架不是阅读的一部分，会把「打开就读」变慢

三、它的限制，就是我们的需求清单

易笺的限制轻阅的对策
单本上限 128 MB无上限：流式扫描 + 16 KB 块索引，边索引边可读，不整书入内存
网络字体需联网，离线失效字体全部本地：内置三套子集 + 用户拖入字体，FontFace 从 IndexedDB 读取
官网 / 服务不可用就打不开（其官网现已 404）PWA 预缓存应用外壳，断网冷启动可用；没有服务端也能是完整产品
隐私模式下书架被禁用隐私模式下退化为「临时书架」（内存态），本次会话仍可读，只提示不持久化
仅中英双语界面中文优先，文案走 i18n 字典；阅读正文不受语言限制
广告规则只覆盖两家来源规则可增删、可预览命中；支持用户自定义正则并本地保存
没有书签、摘录、搜索三个都补上，且全部离线可用
以桌面为主，移动端体验弱移动优先设计点击分区与抽屉，再用同一套代码放大到桌面
阅读进度只在本地浏览器本地为唯一真相；同步为可选，冲突按时间取新、书签并集合并

四、值得抄进细节里的五件小事

「快读完」提示

进度 > 90% 时，在底部显示「还剩约 8 分钟」，而不是继续显示百分比。

章节名主干提取

把「正文 第一卷 原上草 第一章 秦少爷初临宝地」压成「秦少爷初临宝地」，只在目录里压，不改原文。

重处理的快捷键

Alt/Option + 点击封面强制重建索引——识别错了不用删书重导。

目录与正文可拖分隔条

宽度记忆到本地，窄屏自动折叠为抽屉。

缓存即加速

解析结果落库，二次打开不再扫描；同时保留原始文件，随时可重建。

快捷键可关

很多人用输入法，全局快捷键会抢键。开关放在设置里，默认仅阅读页生效。

标志与图标

Mark

符号仍是「一页纸的折角」——折角既是纸的痕迹，也是书签与进度；折角用朱砂，呼应易笺封面上的那条丝带与藏书章。

轻阅QINGYUE
Primary lockup · 横向主标
轻阅QINGYUE
Reverse · 夜间 / 深底反白

构造

画布　80 × 104，页身 60 × 96，左右留白 10。

折角　边长 22（页宽 36.7%），严格 45°，右侧与顶部齐平，填朱砂。

圆角　页角 6，折角处 0——折痕必须是尖的。

描边　4.5（随尺寸等比），线端圆角，拐角斜接。

字标　楷体骨架，「轻」末笔上扬 4° 与折角同向；字距 +10%，不用描边。

小尺寸与图标

16px 以下不用描边版：改为实心页身 + 折角负形，保证 favicon 与任务栏上仍是「一页纸」。

使用禁忌

不描边渐变、不加内阴影与外发光
不旋转折角，不把折角改为圆角
不把折角换成星星、云、流苏
不在彩色照片或封面上直接压标志
字标不改字重，不加描边
图形与字标间距不小于图形宽度的 1/2
安全区：四周留白 ≥ 图形高度 25%。App 图标内页身占画布 62%，四周留裁切余量（Android adaptive icon 前景层安全区 66%）。

配比与规则

Typography

正文排版样例（楷体 18 / 1.95）

桃花源记

晋太元中，武陵人捕鱼为业。缘溪行，忘路之远近。忽逢桃花林，夹岸数百步，中无杂树，芳草鲜美，落英缤纷。渔人甚异之，复前行，欲穷其林。

林尽水源，便得一山，山有小口，仿佛若有光。便舍船，从口入。初极狭，才通人。复行数十步，豁然开朗。

楷体负责「味道」，宋体负责「长读」。默认给楷体，是因为易笺的读者已经用脚投票：纯文本最像书的那一刻，是楷书。

Reading Rhythm

参数不是设置项，是手感。默认值必须一打开就舒服；可调项只是给不同眼睛留余地。

规则细节

行长与留白

屏宽超过 900px 时不再放大行长，只增加左右留白并居中。宁可留白，不要长行——这是易笺被用户提得最多的意见。

空行归一

连续空行最多折算为 1 个段距；段首全角空格移除后由缩进接管，避免双重缩进。

标点

全角标点；行首禁则（，。、；：？！）」』】等不出现在行首）；省略号与破折号不折行。

章节识别

「第 N 章 / 回 / 卷 / 节」「序 / 楔子 / 番外」「Chapter N」；支持行首 [::] 手动标记，以及「从本书学习标题规律」。

脚注排版

正文 ①–㊿ 上标为靛蓝可点；注释行字号 0.86×、缩进 0、左侧 2px 竖线，与正文视觉分层。

中西混排

中文与拉丁、数字之间自动插入 1/4 空隙；数字用等宽数字，翻页时不跳动。

07

日间 / 夜间模式

Day & Night

三档：纸黄（日）、黛蓝（夜）、宣纸（护眼）。默认跟随系统；手动选择后以手动为准并永久记忆。易笺还允许改主题色，我们保留「换主题色」但给出三组预设，避免读者调出低对比度组合。

行为规则
首次启动读系统主题并跟随变化，除非用户手动改过
手动切换写入本地偏好，停止跟随；设置页提供「跟随系统」复位
主题色预设三组：靛蓝（默认）/ 松烟 / 赭石；自定义色必须通过对比度校验才能保存
切换动效颜色 280ms ease 过渡；不做整屏翻转；保留阅读位置与滚动锚点
阅读器独立阅读器可单独设定主题，与界面不同（例如界面日间、正文夜间）
封面夜间封面亮度降至 88%，不反色——反色会让书看起来「坏掉了」
夜间的对比度比日间低一档（15:1 vs 13.8:1 的观感）：暗光下过高对比会产生光晕，这也是易笺夜间用暖白而非纯白的原因。

界面结构

Architecture

易笺的结构极其克制：书架 → 扉页 → 正文，左侧章节栏，底部页码。轻阅在这条主线上只加了三个抽屉：目录、书签、排版。

/ shelf
书架
  • 顶部虚线导入区（拖拽 / 点击 / 批量）
  • 在读（按最近阅读）
  • 未读（按书名）
  • 读完（按完成时间）
  • 搜索：书名 / 作者 / 正文
  • 书籍操作：重命名、改封面色、重处理、删除
  • 存储用量与「本机模式」状态
/ read/:id
阅读
  • 扉页（书名 + 作者 + 藏书章 + 简介）
  • 正文（按章分页 / 滚动）
  • 左侧章节栏（简化名，hover 全名）
  • 底部页码条 + 剩余时间
  • 抽屉：目录 / 书签与摘录 / 排版
  • 脚注浮层、选中菜单
  • 快捷键：←→ PgUp/PgDn Esc
/ settings
设置
  • 外观：主题、主题色、界面字号
  • 阅读：字体、字号、行高、行宽、段距、缩进、对齐
  • 识别：章节规则、[::] 说明、清洗规则
  • 字体：内置三套 + 导入自备字体
  • 数据：缓存、导出备份、清空
  • 同步（可选）：未配置即「单机模式」

动效与可达性

Motion & A11y

动效只解释「什么变了」，不表演。所有阅读器动效均可被 prefers-reduced-motion 一键关闭。

场景时长曲线描述
控件淡入180mscubic(.2,.7,.3,1)透明度 0→1 + 位移 4px
控件退场240msease-out先隐后收，不拖影
抽屉上浮240mscubic(.22,1,.36,1)translateY(100%)→0
主题切换280msease仅颜色过渡，不做遮罩扩散
翻页180msease-out横向 12% 位移 + 淡入，不做仿真翻书
目录跳转0ms—立即定位，不做平滑滚动（长文会卡）
